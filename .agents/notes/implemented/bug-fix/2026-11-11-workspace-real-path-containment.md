# Agent Note: Workspace Real Path Containment

Status: implemented

## Problem

字符串路径可以位于工作区内，实际指向工作区外。符号链接和 Windows junction
会绕过只比较相对路径的检查，连只读工具和审批预览也能读取外部文件。

## Decision

内置工具在使用路径前检查真实位置。文件和命令启动目录必须位于工作区的真实路径下。
创建文件时由最近的真实父目录确定边界。指向工作区内部的链接可继续显式使用，
递归扫描保留跳过链接的行为。无法解析的悬空链接拒绝使用。

## Alternatives considered

**拒绝所有链接。** 这可简化校验，但会让指向工作区内部的链接以及通过链接打开的
工作区失效。保留这些入口可以在校验真实目的地的同时维持正常工作流。

## Consequences

路径检查需要查询文件系统。命令子进程仍以当前操作系统用户权限运行。校验和
后续文件操作之间依赖路径稳定，对抗其他进程并发替换目录需要操作系统级隔离。
